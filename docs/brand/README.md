# Brand

The OrcaSlicer MCP mark: one printed line traces a speech bubble and ends at the tool, the amber dot.

OrcaSlicer MCP is an independent project. The mark avoids OrcaSlicer's orca logo, wordmark and teal on purpose, so please don't represent this project with OrcaSlicer's own logo.

## Files

| File | Use |
| --- | --- |
| `icon.svg`, `icon-512.png` | App and plugin icon. Also used as `mcpb/icon.png`. |
| `logo-horizontal-light.svg`, `logo-horizontal-dark.svg` | Icon and name side by side. README header. PNGs at 240 px tall sit beside them. |
| `logo-stacked-light.svg`, `logo-stacked-dark.svg` | Icon above the name, for centred layouts. |
| `wordmark-light.svg`, `wordmark-dark.svg` | The name alone. |

`light` files go on light backgrounds and `dark` files on dark ones. The icon is the same in both.

## Colours

| Role | Hex |
| --- | --- |
| Tile, text on light backgrounds | `#232428` |
| Line, text on dark backgrounds | `#F2EEE6` |
| Tool dot | `#FFB547` |

## Type

[Geist](https://github.com/vercel/geist-font) (SIL Open Font License 1.1). "OrcaSlicer" is Regular and "MCP" is Bold. The text in the SVGs is converted to outlines, so the files don't need the font installed.
